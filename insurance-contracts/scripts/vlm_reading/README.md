## この 3 回で見つかった欠陥（すべて修正済み）

1. **W6：目次のリーダー罫**が PDF のテキスト層に「.」として入り CER を壊していた。
2. **W5：予測に使う語彙が未定義**（`kind` を当てられない）。
3. **X3-1：列挙として組んだ表**が「表」として二重に数えられていた（TEDS 0.2663 → 1.0）。
4. **X3-2：`outline` に番号のある項**を入れることが未記載（F1 0.5778 → 0.9841）。
5. **X3-3：キャプションの突合**が正規化されていなかった。
6. **X3-4／Y1：`header_cols` の宣言漏れ**（274 表中 25 表）。lint L17 を新設・強化。
7. **X4：図の辺ラベルの重なり**と連結線の貫通。

`life`（3 本目）では**新しい欠陥は出なかった**。3 ジャンル・3 版面で本文 CER は
いずれも 0.001 未満で、ハーネスと正解データは外から使える状態にある。
