# reference_structures.md — 実在契約書の構造分析

> 新 doctype の構造設計、`samples/` の取り扱い、blueprint の骨組みを決める作業では、
> **着手前に必ず本ファイルを読む**こと。
> 先行例：`../insurance-contracts/docs/reference_structures.md`（A〜F 群のカタログと分析ログの型。
> 14 件を分析した実績がある）。分析道具は `scripts/analyze_reference_pdf.py`
> （**構造だけを測り、本文を一切出力しない**）。

## 0. 転載禁止（最重要・CLAUDE.md §0.4-1）

- `samples/` の文書を読んでよいのは**構造・要素の種類・レイアウト慣行を把握するためだけ**。
- **文章はメモにも残さない。** 分析ログに書いてよいのは「第5条相当に秘密情報の例外の列挙（4 項目）がある」
  「冒頭に当事者・物件・賃料を並べた表がある」のような**構造記述のみ**。
  例文が要るときは、その場でオリジナルを作文する。
- **「公的機関のひな型だから著作権はない」と判断しない。** 判断に迷う素材は使わない。
- **模倣は文章より「条の並び順」「列挙の順序」「数値の列」「様式の項目の並び」に出る**
  （`docs/style_guide.md` §2.1）。**分析ログに数値の列や項目の並びをそのまま書き残さない**
  （「料率表は 3 段」と書くのは可、「5%・3%・1%」と書くのは不可）。
- `samples/` の PDF は**リポジトリにコミットしない**（`.gitignore` で除外。`samples/SOURCES.md` だけ残す）。
  スクリーンショットも保存しない。**目視と構造メモのみ。**
- 生成物が参考文書に似ていないことの最終確認は**人間の担当**（`HITL_TODO.md` H3）。
  AI は参考文書を読んでいるため、無自覚な写しを自分では否定できない。

## 1. 分析の手順（P1。doctype 追加ごとにも実施する）

1. 対象は `samples/<category>/`（出典・入手日は `samples/SOURCES.md`）。
   同一カテゴリ内で**発行元・体裁が異なるもの**を見る（公的機関の標準様式／業界団体のモデル契約／
   法律事務所のサンプルで、骨格がかなり違う）。
2. `scripts/analyze_reference_pdf.py` でページ数・判型・段組・記号の出現数・表の件数と列数・
   ヘッダ/フッタの有無を測り、代表ページを**目視**する。既知の計測の癖（yakkan で実測）：
   - **段組の自動判定は幅広の表があると誤る。段組は目視を正とする。**
   - 和文 PDF は `extract_text` が字間に空白を入れる。空白を潰してから数える。
   - MediaBox の原点が (0,0) でない PDF がある。ToUnicode の無いフォントはテキスト計測不能
     （その場合は「目視のみを根拠」と明記する）。
   - **逐条解説つきモデル契約書は「契約書本体」と「解説」が混在する。** 本体だけのページ数を別に数える
     （生成対象は本体であり解説書全体ではない）。
3. 次の観点で**構造だけ**を書き出す：
   - 前付け・後付け：表紙／目次／前文／当事者表示／**頭書**／記名押印欄／収入印紙欄／改定履歴の有無と位置
   - 階層と番号方式：何階層か、各階層のラベル書式、第1項が無番号か、条見出しの位置（inline / above / plain）、
     章を使うか、条は通し番号か、別紙・様式の独立体系、枝番の有無
   - 当事者：何者か、呼称（甲乙／役割名）、導入の書き方（前文内か当事者表示か）、記名欄の並び（縦／横）
   - 表の類型：意味種別・結合セル・ヘッダ行列数・表下注記・繰返し表頭・**記入欄か参照表か**
   - 図の類型：フロー／ツリー／タイムライン／ステップ／マトリクスのどれに落ちるか（**契約書は図が少ない**）
   - 参照と注：条項間参照の表記（「前条」「第◯条」「別紙◯」「頭書」）、脚注・注記・逐条解説の流儀
   - ページ装飾：ヘッダ/フッタ・ページ番号書式（`- 1 -` 型か）・見出し装飾・罫線の太さ
4. 書き出した特徴を**読み取り課題カタログ**（CT1, CT2, …）として §3 に整理し、各課題を blueprint の
   `required` へ写像する。**必須要素は構造で縛り、semantic_type で題材を縛らない。**
5. カタログに現れた**コアで表現できない構造**があれば、`docs/schema.md` への提案として
   `docs/decisions.md` に起票する（**勝手にコアを拡張しない**）。
   **正解が作れない体裁は再現対象にしない**（yakkan：縦組み見出し・ルビは実測のうえ不採用）。

  → blueprint の `target_pages` は前者に合わせ、約款型・頭書型だけ大きくする（`docs/doctypes.md`）。
- 同一カテゴリ内で**ページ数が一桁違う**（`lease` の 4 と 30、`employment` の 2 と 24）。
  これは**骨格が別類型**であることの表れ（法律事務所の短いサンプル vs 国交省の標準契約書＋別表）。
  → doctype ごとに variant で両方を作る価値がある。

## 4. 分析ログ（P1 でここに追記する）

形式：

```
### #N 2026-XX-XX <カテゴリ>/<ファイル名>
- 出典: samples/SOURCES.md の該当行（URL はそちらにある）
- 骨格類型: 条文型 / 頭書型 / 様式型 / 約款型 / 逐条解説型
- 構造メモ:
  - 前付け: （表紙・目次の有無と位置）
  - 階層: （何階層・各階層のラベル書式・条は通し番号か）
  - 当事者: （何者・呼称・導入の位置・記名欄の並び）
  - 表: （件数・類型・結合の有無・ヘッダ行列数）
  - 図: （件数・類型）※契約書は 0 件が普通
  - 参照: （条項間・別紙・頭書の表記）
  - 装飾: （ヘッダ/フッタ・ページ番号書式・罫線）
- カタログへの反映: CT4 の実例 / CT17 を新設
- 判断: 再現対象にする / しない（理由）
```

**文章の引用は一切しない。** 1 文書 10〜20 行に収める（長く書くほど写しに近づく）。

計測は 39 ファイル全件（`scripts/analyze_reference_pdf.py`。生ログは `scratch/p1/measure.txt`、
リポジトリには入れない）。目視は各カテゴリ 2〜3 ファイル（下の「目視」欄が `あり` のもの）。
**目視していないファイルの記述は計測値だけを根拠にしている**ので、そう明記してある。

### #1 2026-09-27 nda/（4 ファイル。目視: nda_01 p2・nda_02 p5・nda_04 p1）

- 骨格類型: **条文型**（4 件中 4）。うち 2 件（26p・24p）は条文＋解説の合本で、契約書本体は 5〜8 ページ相当。
- 階層: 条 → 項 → 号の 3 階層。**条は全編通し番号**（章を使うのは 1 件のみ、6 章）。
  第1項に番号を振る流儀（nda_01）と振らない流儀（nda_04）が**両方ある**。号は半角 `(1)` と全角 `（1）` が割れる。
- 条見出し: インライン。括弧の種類が `（…）` と `［…］` に割れる。
- 当事者: 2 者・甲乙。前文で導入（当事者表示の欄を持つものは無い）。記名欄は縦並び。
- 表: **0 件**（4 件とも）。列挙はすべて号の箇条書きで、罫線表を使わない。
- 図: 0 件。
- 参照: 条項間は「第◯条」「前条」「前項」。別紙は 2 件で使用（15 回・3 回）。
- 装飾: ヘッダ無し。フッタはページ番号のみ。24〜26p の 2 件は目次（リーダー罫 17 回）を持つ。
  解説つきの 2 件は**脚注記号 `（＊N）` を 92 回**使い、枠囲みの規程例の直後に注を置く。
  nda_01 は**版面の右 1/3 を注釈帯にした 2 領域レイアウト**（本文は左 2/3）。
- カタログへの反映: CT10・CT11・CT16 の実例。**CT17（右余白の注釈帯）を新設**。
- 判断: 条文型は再現対象。右余白の注釈帯は**再現対象にしない**（1 段組固定の決定と衝突し、
  正解の読み順が版面依存になる）。

### #2 2026-09-27 outsourcing/（4 ファイル。目視: outsourcing_01 p1/p3・outsourcing_02 p4・outsourcing_03 p1）

- 骨格類型: **条文型**（2 件）／**解説書に埋め込まれた参考例**（1 件）／**発注書の記載例集**（1 件）。
  後の 2 件は契約書ではない。計測の表・敬体の多さはガイドブック側の地の文に由来する。
- 階層: 条 → 項 → 号 → 細目の 4 階層。項ラベルは `1.` `2.`（**第1項にも番号**）。号は全角 `（1）`、細目は `①`。
  号が「小見出し＋改行して説明段落」を持つ形が目立つ。
- 当事者: 2 者・甲乙（委託者／受託者）。前文で導入。記名欄は縦並びで **`住所：` `社名：` `代表者名` `印` のラベル付き**。
- 表: 条文型 2 件は 0 件。発注書の記載例集は**記入欄の表**（2 列・項目名 × 記載内容、結合セルあり、表下に備考）。

- 参照: **基本契約と個別契約（発注書）の 2 文書構成**。本文が個別契約を指し、個別契約が基本契約を指す。
- 装飾: ヘッダ無し／フッタはページ番号。解説書の 1 件だけ色帯・囲み・引出線つき注釈を持つ。
- カタログへの反映: CT5・CT14 の実例。**CT18（選択欄を「囲み線で囲む」形で表す）を新設**（発注書の `有り・無し`）。
- 判断: 条文型＋別紙（個別契約の様式）を再現対象にする。引出線つきの注釈は**再現対象にしない**（解説書の体裁）。
